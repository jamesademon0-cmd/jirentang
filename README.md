# 济仁堂中医养生馆 · 官网

> 调和阴阳 · 固本培元

一个新中式风格的养生馆官网，纯 HTML + CSS + JavaScript 构建，零依赖、易部署。

## 模块构成

| 文件 | 作用 |
|------|------|
| `index.html` | 11 大板块主结构（首页 / 简介 / 名医 / 项目 / 理疗 / 小课堂 / 四季 / 预防 / 义诊 / 见证 / 联系） |
| `styles.css` | 新中式视觉系统（青墨绿 + 朱砂红 + 中式金） |
| `script.js` | 滚动状态、汉堡菜单、入场动画、课堂 tab、预约表单、字数递增 |

## 本地预览

```bash
python -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765
```

## 部署

项目零依赖，静态托管即可（GitHub Pages / Vercel / Netlify / 七牛 / 阿里云 OSS 等）。
推送到 `main` / `master` 分支后即可直接通过 Pages 访问。

## 待替换的占位内容

- 医馆名 / Slogan（全局搜索 "济仁堂"）
- 联系电话 / 邮箱 / 地址（联系方式区）
- 价格（`¥198 / 次` 等）
- 医生姓名/介绍（名医团队区）
- 客户评价（见证区）
- 义诊活动日期与地点

找到后替换即可上线。
